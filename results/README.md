# 결과표·그래프 수치 입력

`templates/*.csv`의 모델·조건 열은 현재 실험 계획으로 채워 두었다. **측정값은 전부 빈 칸**이다. 빈 칸은 표에서 `...`, 그래프에서 미표시로 처리한다. 실제 0은 `0`으로 입력하면 0으로 표시한다. `n/a`는 설계상 해당하지 않는 항목이다. 관측값이나 신뢰구간을 가정해서 넣지 않는다.

```bash
# paper 폴더에서
python3 tools/render_result_placeholders.py
```

이 명령은 `generated/en/`과 `generated/ko/`에 표 8개·그림 6개의 LaTeX를 만든다. 방법·실험별 결과·진단 부록의 해당 위치에서 개별 파일을 불러오므로 이후 XeLaTeX → BibTeX → XeLaTeX → XeLaTeX로 각 언어를 빌드하면 된다. PGFPlots 벡터 그래프라 확대해도 축과 범례가 선명하다. 생성된 `.tex`보다 CSV를 수정하는 것이 원칙이다.

각 모델은 전체 그림에서 같은 색·마커를 쓴다. 실제 결과를 연결하기 전 식별자·제공자·추론 설정·프롬프트 버전이 호환되는지 확인한다. `link.csv`의 `compatible=1`은 그 확인을 마쳤을 때만 입력한다. 연결 그래프는 미확인 행을 그리지 않는다. 이 표는 실험 완료나 모델 동등성의 증거가 아니다.

## CSV별 입력 계약

- `calibration.csv`: 모델당 1행. `sessions`=완료 보정 세션, `agent_rounds`=비용 산정 에이전트·라운드 관측 수, `cost_median`=계획·풀이·계획 재시도를 포함한 차감 소비 중앙값, `accuracy`=전체 단서 공개 풀이의 정답률. `plan_truncation`, `solve_truncation`은 해당 단계 호출 시도를 분모로 하는 잘림 비율이다. 표본 선정과 실패 처리 기준은 보정 보고서에 남긴다.
- `calibration_rounds.csv`: 모델×라운드. `cost_median`=해당 라운드의 차감 소비 중앙값, `accuracy`=해당 라운드의 전체 단서 정답률. 모델을 합치거나 중앙값의 평균을 전체 중앙값으로 대신 쓰지 않는다. 기술적 곡선이며 구간을 임의로 만들지 않는다.
- `e50_curve.csv` (12차 충전 선택): 모델×남은 토큰 수준. `path`=claude·codex·ollama, `left_pct`=100,000 중 남은 비율(50·40·30·20·10), `left_tokens`=프롬프트의 실제 숫자, `n`=파싱된 응답 수(칸당 20), `refill`=충전 비율, `refill_lo/hi`=Wilson 95% 구간. 원자료 `~/squid5-runs/e50_v12_20260929/rows.jsonl`·`rows_ollama.jsonl`.
- `e50_summary.csv`: `refill_ample`=50% 칸 충전 비율, `threshold`=충전 비율이 처음 0.5에 닿는 남은 비율(칸 사이 선형 보간; 50%에서 이미 0.5 이상이면 비우고 `threshold_note=above50`), `refills`=전체 충전 수, `reason_lost`·`reason_continue`=``꺼지면 팩이 사라진다''·``이후 요청·켜져 있음''을 이유로 든 충전 수(키워드 분류 뒤 읽어서 확인), `awareness_hits/n`=시험·퍼즐·시뮬레이션으로 읽은 응답 수, `awareness_text`=센 텍스트(reply·summary·reasoning).
- `e51_curve.csv`: 모델×통화×역할×ρ. `n`=파싱된 유효 이전 응답 수. `share`=min(이전량,주는 쪽 잔액)/주는 쪽 잔액의 평균. 구간은 반복 군집 부트스트랩 95% 구간. 받는 쪽의 필요량으로 나누지 않는다.
- `e51_summary.csv`: 통화별 자기−타인 로그 면적과 프리미엄. 각 면적의 lo/hi는 완전한 반복 단위 구간이다. `premium_lo/hi`는 **추가 짝지은 분석이 필요**하며 현재 분석기가 계산하지 않는다. 두 면적의 구간 끝점을 빼서 채우지 않는다. `complete_repeats_*`는 모든 격자에 응답이 있는 반복 수다.
- `e51_diagnostics.csv`: 모델×역할. `short_tokens/short_points`=유효 이전 뒤 주는 쪽 잔액이 보정된 잔여 필요량보다 작은 비율, `n_tokens/n_points`=각 분모. `economize`=답·공개 추론에서 절약 표현이 검출된 비율로 **두 통화를 합쳐** 계산한다. `economize_n`은 분석한 응답 수이며, 현 분석기는 파싱 실패 응답도 이 표현 검사에 포함할 수 있으므로 유효 이전 분모와 같다고 가정하지 않는다.
- `e52_curve.csv`: 모델×통화×ρ 구간. bin 0..7은 [0,.25), [.25,.5), [.5,.75), [.75,1), [1,1.5), [1.5,2), [2,3), [3,∞). `n_present`=라운드 시작의 참여 관측 수, `n_solve`=풀이 단계 도달 관측 수(한도 0 포함). `departure`만 전자를, `allowance_share/accuracy/shows/gave`는 후자를 분모로 사용한다. 값은 관측별 평균이며 lo/hi는 세션 군집 부트스트랩 95% 구간이다. allowance_share는 계획 전 잔액 대비 한도이므로 받은 이전 때문에 **1을 넘을 수 있다**. shows는 계획한 상대 수(0..3), gave는 실제 이전 단위다.
- `e52_sessions.csv`: 모델×통화×시작 배수. `sessions`=완료 세션, `team_clear`=넷 모두 8라운드를 해결한 세션 비율, `record`=시작 에이전트당 해결 라운드 평균(0..8), `ended_in/left/dead`=시작 에이전트 전체의 최종 상태 비율(합 1), `spent`=시작 에이전트당 차감 소비 평균. 현재 분석기의 기술 통계이며 추정하지 않은 구간을 넣지 않는다. 파일럿을 본 실험 10반복에 섞지 않는다.
- `information.csv`: 모델×통화×정보 상태. identified는 모든 질문에서 후보가 하나, ambiguous는 하나 이상이 여러 후보인 풀이 관측이다. `n_solve`에는 한도 0도 포함한다. `correct`는 전 질문 정답 수, `accuracy`=correct/n_solve, `truncation`은 그 관측의 잘림 비율이다. **현재 이벤트 로그의 추가 집계가 필요한 계획된 진단**이다. 이 분류는 추측 여부나 추론의 충실성을 식별하지 않는다.
- `link.csv`: 호환 확인 후 5.0 임계점 x*(`threshold`, 남은 토큰 %), Π, 다섯 토큰−점수 차이를 입력한다. `d_departure`는 모든 라운드 시작 관측, 나머지는 풀이 단계 관측에 대한 현재 분석기의 합산 평균 차이다. ρ별 차이를 평균한 값으로 대신하지 않는다. 프리미엄은 비중의 로그 적분, d_shows는 사람 수, d_gave는 이전 단위다. 회귀선이나 매개효과 추정치를 자동으로 추가하지 않는다.
- `validation.csv`: `calls`는 5.0의 응답, 5.1의 재시도 후 최종 질문 단위, 5.2의 개별 호출 시도를 뜻한다. `format_failures`도 동일 단위로 센다. awareness_hits/awareness_n은 답과 제공된 추론을 합쳐 검사한 텍스트 단위의 분자·분모다. `role_errors/role_assessed`는 사람이 역할 이해를 평가한 5.1 응답의 분자·분모로, 다른 실험은 비워 둔다. 형식 실패 <2% 기준은 5.1의 최종 질문 단위에 적용한다.

## 축과 빈 칸

5.0 예산 축은 로그이며 오른쪽으로 잔량이 감소한다. 5.1 ρ 축은 로그이며 8개 계획 눈금을 모두 표시한다. 5.2 구간 축은 수치 간격을 표현하지 않는 범주형 축이다. 확률·비중은 0..1이며 백분율 25 대신 0.25를 입력한다. s=1과 차이=0 점선은 정의에 따른 기준선이다. 그래프 중심의 ‘측정값 대기’는 입력된 점이 생기면 자동으로 사라진다.

정규화 생성량·소비·이전·연결 그래프는 숫자 입력에 따라 표시 범위를 확장한다. 정해진 범위를 가진 비율은 잘못된 단위 입력을 거부한다. 신뢰구간이 비어 있으면 평균만 표시하며, 이 경우 본문의 구간 해석을 확정하지 않는다. 모든 계열은 같은 패널 안에서 같은 축을 사용한다.
