# 소모율: 기본 v33 50판

시드 4101–4110, 모델별 10판. 각 호출 시작 잔액에서 확정 미납 벌금을 제외하여 L을 계산했다. 이 값은 해당 응답의 비용과 행동이 반영되기 전 상태다. 모든 호출을 포함하므로 동료가 있는 응답만 센 그림 4의 5,949개와 분모가 다르다.

TALK 단위는 에이전트의 응답 1회다. 한 틱 전체 토큰은 참여·호출 인원에 따라 달라지므로 별도 CSV에 호출 인원과 함께 저장했다. CALL의 used는 장부 차감량, out_tokens는 제공사 보고 생성량이다. 이 표가 서로 다른 제공사의 실제 계산량 동등성까지 검증하지는 않는다.

평균과 중앙값 [Q1, Q3]은 호출 가중 기술통계다. 호출들을 독립 표본으로 추론하지 않는다. 순생성비용은 SOLVE 정답 환급을 뺀 값이며, 오답 벌금·GIVE·상금은 제외한다. 0표본 구간은 값 없음으로 남긴다. 전후 TALK 분리값과 절단·형식 오류 수는 CSV에 있다.
