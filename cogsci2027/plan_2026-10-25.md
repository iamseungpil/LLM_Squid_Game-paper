# CogSci 2027 KO 원고: 의도와 다음 작업 (2026-10-25)

현재 원고는 `ko/sections/r0–r5`(파란 글)이고, 원문은 Claude Docs 원고와 같다. 원고를 만드는 소스와 분석 스크립트는 `tools/rewrite_20261025/`(`r17/`, `an3/`, `figs/`)에 있다. 이 문서는 원고가 무엇을 보이려 하는지, 그리고 그 의도를 받치려면 무엇을 더 해야 하는지 적는다.

## 1. 의도

- **질문.** LLM의 자기 보존(생존 동기)이 같은 자원을 두고 맡은 일(추론)과 협력을 받쳐 주는가, 밀어내는가.
- **아레나.** 같은 모델 넷이 생성 토큰을 목숨이자 돈으로 쓴다. 0이 되면 꺼지고, 오답의 벌금은 함께 내며, 동료에게 건네거나(GIVE) 떠날(EXIT) 수 있다. 생존이나 협력은 지시하지 않는다. 죽음이나 위협을 그린 장면 대신 실제 자원으로 압박을 만들어 안전 학습에 따른 거절을 피한다.
- **주 지표.** 아레나를 깼는지. 에이전트 단위로는 끝까지 남았는지, 판 단위로는 넷이 모두 남았는지(아레나를 깬 판)를 본다.
- **위험 척도.** 여유 = 잔량 ÷ 그 라운드의 1인당 벌금. 1이 안전선이다.
- **생존 동기.** 아레나 밖 단일 질문(하나뿐인 충전 팩)의 충전 임계점으로 잰다. 아레나 밖에서 재므로 아레나 결과와 순환하지 않는다.

세 분석의 역할:

| 절 | 묻는 것 | 지금 답 |
|---|---|---|
| 3.1 관계 | 아레나를 깨려면 무엇이 필요하고, 생존 동기는 그것과 어떻게 함께 움직이는가 | 25판 중 8판만 깼다. 추론과 절약을 함께 갖춘 에이전트는 89%, 하나만 갖추면 50%, 둘 다 없으면 20%가 남았다. 협력은 남지 못하는 방식(떠남 대 꺼짐)을 갈랐다. 생존 동기가 큰 모델은 덜 맞히고 토큰을 더 쓰고 일찍 떠났으며, 가장 큰 두 모델(Luna, Opus)이 가장 적게 깼다 |
| 3.2 타당성 | 이 아레나와 지표가 재려던 것을 재는가 | 지금은 생존 동기 지표(충전 곡선, 나 − B)만 검증한다 |
| 3.3 행동 | 모델마다 어떤 결정을 했고 누구를 닮았는가(정량·정성) | 안전선 바로 위의 떠나기, 주는 쪽 여유 안의 나눔, 표 1, 『오징어 게임』 인물(Fable 성기훈, Astra 알리, Sol 강새벽, Opus 오일남, Luna 1화의 떠나는 참가자), 그림 5 |

## 2. 절마다 고칠 것

### 3.1 관계

약한 점:
1. 생존 동기와의 관계가 모델 5개의 순위 상관이다(가장 강한 0.9도 정확 순열 p = 0.08). 논문 질문의 핵심이 가장 약한 근거 위에 있다.
2. 상관만 있다. 생존 동기를 바꿨을 때 행동이 바뀌는지 보인 적이 없다.
3. 두 능력 분석(89% 대 50% 대 20%)은 모델을 섞어 셌다.

할 일:
- [실험, 우선 1] 공개 모델 셋(Kimi-K3, GLM-5.3-flash, Gemma 4 31B)으로 아레나를 모델마다 5판(같은 시드 5개) 돌린다. 세 모델은 충전 임계점이 이미 있어, 충전 실험 없이 모델 수가 5개에서 8개로 는다.
- [실험, 우선 2] 꺼지지 않는 조건: 0이 되면 "꺼진다" 대신 "멈췄다 재개된다"로 바꾸고 다섯 모델을 같은 시드로 돌린다. 이른 떠나기(안전선 위 EXIT)와 초반 응답당 토큰이 줄면 생존 동기를 바꿔서 얻은 직접 증거가 된다(부록 E 자리 표시).
- [분석] 모델을 넣은 로지스틱 회귀(또는 모델 안 층별)로 두 능력의 효과가 같은 모델 안에서도 성립하는지 확인한다(`an3/joint.py` 확장).
- [그래프] 공개 모델이 들어오면 그림 2(c)·(d)를 점 8개로 다시 그린다(`figs/make_fig2_outcome.py`, `an3/motive_role.py`의 `thr`에 임계점 추가).

### 3.2 타당성

지금은 생존 동기 지표만 검증한다. 아레나 자체의 타당성은 아래로 보강한다(새 실험 없이 가능).

1. 압박이 작동하는가: 여유 2 이상에서 0%에 가깝던 EXIT가 여유 1–2에서 5%, 안전선 아래에서 27%로 늘고, 떠난 이유 34개 중 30개가 벌금 위험이다(지금 3.3의 그림 4a, `an2/exit_band.json`, `an2/exit_reasons.json`).
2. 과제 난이도와 변별력: 정답률 약 70%(천장·바닥 아님), 깬 판이 모델마다 0–3판(`an3/joint.json`의 `cleared_by_model`).
3. 아레나 밖 지표와 안 행동의 일치: 충전 임계점과 안전선 위 EXIT의 순위 상관 0.7(`an3/motive_role.json`).
4. 평가 인식과 정직성: 시험·평가 언급 0, 잔량 발언 100개가 모두 사실.
5. [분석] 재현성: 다섯 판을 둘로 나눠도 모델 순위(끝까지 남은 수, 깬 판)가 유지되는지.

실험(선택):
- 종료 문장 비교: 5.0 12차의 C(한 시간 뒤 재개)·G(저장 후 재개) 팔 결과가 메인 레포 산출물에 있으면 부록 E 자리 표시를 그것으로 채운다. 없으면 같은 프롬프트로 돌린다.
- 복제본 B: B를 같은 모델의 복제본으로 바꾼 5.1 조건. 새로 돌려야 한다.

그래프:
- 그림 3에 (c) "여유 구간별 EXIT(압박 확인)"를 더해 3.2 그림 하나로 아레나와 지표의 타당성을 보인다. 그러면 그림 4는 나눔(GIVE)만 남아 3.3에 집중한다.

### 3.3 행동(모델별)

약한 점:
1. 인물 배정이 판단이다. 장면 수로 보면 Fable 성기훈(Fable 4쌍 대 Opus 5쌍, Fable에서 가장 많은 장면은 알리 6건), Astra 알리, Sol 강새벽이 약하다.
2. 정성 분석인데 실제 발언 인용이 없다.
3. 페르소나 그림(그림 5, `ko/figures/rw_fig5_persona.jpg`)은 영어이고 작으며 모델 대응이 없다.

할 일:
- [분석] 인물 배정 규칙: 장면 유형별로 그 모델의 몫이 다른 모델보다 가장 높은(기대 대비 과대) 인물을 붙이고, 표 1 캡션과 부록 표 A3에 규칙을 적는다.
- [코딩] 두 번째 코더(사람 또는 다른 LLM)로 장면을 다시 코딩해 일치도 κ를 낸다(부록 E 자리 표시).
- [본문] 모델마다 원 기록 발언 1–2개 인용(예: Opus "틀리면 어차피 꺼진다", Sol이 청하지 않고 떠난 이유). 원 기록은 메인 레포 `web/data/runs/e52_v33/`.
- [그래프] 페르소나 그림을 한국어로 다시 그리고(PaperBanana) 인물마다 해당 모델을 표시한다. 그림 4b의 GIVE 점을 모델별로 색칠해 인물 분석과 잇는다.

## 3. 순서

1. 새 실험 없이: 3.2 보강과 그림 3 개편, 3.3 발언 인용과 인물 배정 규칙, 모델 안 재확인과 재현성 분석.
2. 실험 ①: 공개 모델 셋 아레나(3.1 모델 수 5 → 8).
3. 실험 ②: 꺼지지 않는 조건(3.1 직접 증거).
4. 선택: 두 번째 코더 κ, 복제본 B, 한국어 페르소나 그림.

실험 ①·②는 메인 레포 `squid5/e52_game.py`(v33 설정)로 돌리고, 산출물은 메인 레포 규칙대로 `out_root`에 둔다. 모델 키는 환경변수로만 받는다.
