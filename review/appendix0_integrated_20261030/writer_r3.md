# Writer R3

blind_r2_anthropic.md, blind_r2_openai.md, score_r2.txt를 읽고 두 검토의 공통 지적을 중심으로 수정했다. 검토자의 전체 재작성이나 문장 패턴 변경 제안은 적용하지 않았다.

넷째 문단의 추상적 구분 문장과 마지막 문단의 중복 요약 문장을 삭제했다. 16판 비교에서는 6/8의 성공과 2/8의 실패를 바로 붙였고, 다른 집단의 0/8 결과 다음에 인과 해석 제한을 유지했다. 저여유 풀이 6건과 이탈 이후 풀이 부재 설명은 그대로다.

캡션의 반복 관측·인과 및 능력 해석 제한을 (f) 끝에서 전체 캡션 도입으로 옮겼다. 지니의 최댓값 보정과 전부 0인 판 제외, 모델별 유효 판수, 나머지 지표의 5판 평균을 세 문장으로 나눴다. 모든 수치와 분모, 관측 시점, 빈 원 조건, 판 단위 점·분수 설명은 유지했다.

평균 지니가 낮아서 평균 Sen이 높다는 설명은 넣지 않았다. 서로 다른 판 집합의 평균을 곱하는 식으로 읽힐 수 있기 때문이다. 안전선 정의는 안전선을 처음 본격적으로 비교하는 셋째 문단에 남겼다. 앞 문단의 여유는 기존 절에서도 사용하는 개념이며 정의를 옮겨야 할 수치상 문제는 없다.

실제 원고와 그림은 수정하지 않았다. v3.tex와 v3.md는 동일한 본문과 캡션을 담는다.
