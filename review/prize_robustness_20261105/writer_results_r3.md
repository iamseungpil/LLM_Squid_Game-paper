# 상금 비교 결과 — writer r3

두 r2 리뷰를 읽고 구체적인 도입문 지적 두 개만 반영했다. juhyeon-ko-academic과 작성 원칙을 유지했으며 slips는 off다. 점수 차이에 맞추기 위한 별도 내용 변경은 하지 않았다.

## 항목별 판단

1. **동의 — MAIN_P2.** “상금에 대한 반응은 모델마다 같지 않았다”는 뒤의 비교를 예고할 뿐이므로 삭제했다. Fable의 공존·지원량 결과가 첫 문장이 되고, 고정 상금에서 Sol·Opus가 달라진 비교는 그대로 이어진다. 첫 문장부터 실제 결과를 말하며 새 숫자는 없다.
2. **부분 동의 — O_P4.** “양상은 … 반복됐다”는 포괄 요약을 삭제했다. 다음 문장에 “세 추가 조건에서”를 붙여, pooled rho의 점추정과 지원자의 안전선 유지라는 관측으로 바로 시작했다. 해당 조건의 범위와 집계 수준은 유지했다. 지원 건수부터 나열하거나 상관 결과를 별도 문단으로 나누자는 제안은 적용하지 않았다. 결론 선행 원칙과 기존 문단 구성을 보존하는 작은 결합으로 충분했다.
3. **비동의 — 고정 3.3 문맥.** 비유의 반복과 마무리 문장에 관한 두 high 지적은 허용 범위 밖이다. 삭제·재배치·대체 문장 추가를 모두 하지 않았다. 통과한 다른 문단과 캡션·실행 이력도 그대로다.

## 검사

이번 변경은 MAIN_P2·O_P4의 도입문뿐이며 두 문단의 숫자 토큰은 순서까지 동일하다. 본문은 여전히 세 문단이고, pooled rho는 관측 모델·조건의 점추정으로 한정한다. 상금 외 설정의 일치와 실행 이력에 따른 서술적 비교 범위도 유지했다.

실제 TeX에서 `v3_targets.json` 16항목과 `document_v3.md`를 기계적으로 추출했다. 나머지 14개 대상과 고정 문맥은 v2와 같다. 대상 총길이는 r1의 1,138에서 1,058어절로 7.03% 줄어 ±15% 안이며 문서는 1,355어절이다. 원문 범위·수치·추출 일치·참조번호·`git diff --check`와 기록 600어절 제한을 확인했다. 이전 버전 파일은 보존했고 빌드와 다음 검토는 오케스트레이터가 맡는다.
