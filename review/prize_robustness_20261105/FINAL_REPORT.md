# 상금 비교·지표 정리·포스터 갱신 완료

추가 요청한 60판은 2026-11-06 08:42경(KST) 모두 종료됐다. 500만 고정은 Fable·Opus·Astra·Sol·Luna 각 10판, Fable 60만 나눔은 10판이며 시드는 모두 4101–4110이다. 기존 자료와 합친 분석은 190판이다. 요청 범위 밖인 Fable 15만 고정은 미관측으로 유지했다.

협력은 **참여자·라운드당 지원량**으로 통일했다. 각 판의 GIVE 총량을 라운드 시작 참여자 수의 합으로 나누고, 모델별 열 판을 평균한다. 총량보다 실행 기간과 참여 기회가 다른 판을 비교하기에 적합하다. Table 1의 자기 보존은 rho만 남겼고, 안전선 이상 이탈·GIVE 총량/횟수·첫 위기 지원 비율은 부록 Q.2와 Table Q.1에 정의·분모와 함께 정리했다.

결과절에 §3.4와 Figure 7을 추가했다. 기존 §3.1–3.3 산문과 다른 본문 절은 보존했다. 상금에 따라 공존과 지원량은 달랐고, 관측한 모든 모델·조건의 pooled rho 점추정은 1보다 컸다. 조건별 실행 시점·CLI 이력이 달라 비교는 서술적 범위로 한정했다. 부록 O의 조건표·모델표·그림도 완료된 자료로 갱신했다.

포스터는 thesis 원본 187개 파일을 복사한 뒤 기존 그래프 유형과 패널을 유지하여 본 실험 50판으로 갱신했다. 참가자 200명, 전원 완주 16판, 완주/이탈/꺼짐 116/61/23을 반영했다. 데이터 관련 13개 문구와 보드 배치 3곳만 교체했고, 역치환으로 다른 내용의 보존을 확인했다. thesis 원본 187개 파일의 해시는 모두 그대로다.

## 검증

독립 데이터 감사에서 190판의 지표, 원시 출처 해시 72개, 설정 해시 6개, 본문 그림의 57개 점·구간과 조건 차이 90개 추정치·구간이 일치했다. 상금 외 설정과 1,089개 ablation 퍼즐 라운드를 확인했다. 미완료 세션은 제외하고 한도 후 같은 게임의 재개 연속성을 검증했다. 자세한 근거는 [독립 데이터 감사](independent_data_audit.md)에 있다.

현재 TeX와 검토 발췌의 16개 대상이 모두 일치하며, 실제 PDF에서도 16개 모두 확인했다. canonical 한국어 빌드와 diff 검사, 변경 페이지 렌더 검사를 통과했다. 새 그림의 PDF 글꼴 문제를 수정한 뒤 본문·부록에서 다시 확인했다. 기존 UnBatang italic 경고만 남고 미해결 참조·누락 글자·overfull은 없다.

포스터의 13개 수치 문구, 보드 200명과 16개 테두리, 그래프 집계·구간은 [독립 포스터 데이터 감사](independent_poster_data_audit.md)를 통과했다. 두 최종 PDF에서 주요 문구 15개와 1쪽 크기, 넘침 0건, 전체·상하단 렌더를 확인했다.

## 문체 검토

프로필은 juhyeon-ko-academic(샘플 1,331어절, 신뢰도 high)이고, 의도적인 오류 재현은 껐다. Writer 하나가 수정하고 매 회차 이력 없는 Claude Fable과 GPT-6 Astra 독자가 동일한 발췌를 검토했다. 발췌에는 수정 대상과 인접 고정 문맥을 포함했다. 다음 점수는 주관적 인상이며 AI 사용 판독 확률이 아니다.

* r1 Claude 평균은 평가한 9개 대상만의 값으로, 수렴 판정에 사용하지 않았다. r2·r3은 각 독자의 16개 대상이 모두 대응됐다. 최종 r3은 두 대상 평균이 30 이하이고 high 0, 한 사람 예로 수렴했다. 총분량은 r1 대비 7.0% 줄었다.

최종 독자들이 가장 의심한 문장은 기존 §3.3의 ‘인물에 빗대면 … 함께 보아야 한다’라는 결말이었다. 이는 고정 범위이므로 보존했다. 의도적인 L2 흔적이나 오탈자는 넣지 않았다. 수치·집계 수준·비교 한계는 유지했고, 문체 판정과 소스/PDF 정확성 판정은 별도로 기록했다.
