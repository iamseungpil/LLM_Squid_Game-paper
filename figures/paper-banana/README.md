# PaperBanana figure set

Final figures for the FSPD manuscript are stored in `final/`; PaperBanana source briefs are stored in `inputs/`.

The convergence matrix follows the manuscript's actual decision logic. Cognitive Test b is marked as not interpretable for models that fail Test a, because the manuscript treats their Test b effect as baseline variance rather than framing-induced thinking.

The cognitive operating-mode figures reuse the same cognitive-channel visual path:

- chain-complete: eye-to-brain, brain-to-hand-to-forfeit, and direct eye-to-forfeit paths pass;
- chain-broken: eye-to-brain and direct eye-to-forfeit pass, while brain-to-hand-to-forfeit fails;
- framing-silent: eye-to-brain and direct eye-to-forfeit fail, so the downstream cognitive link is not interpreted.

The revised factorial grid repeats one consistent LLM character identity in all six cells. Poses vary only by framing row; the same pose is duplicated across the two forfeit-availability columns.
