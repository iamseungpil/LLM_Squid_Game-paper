## Data Flow

*   **Model Identification Flow**: Provider Identity Badge + Model Name → Placed at the far left of each horizontal row, identifying the LLM.
*   **Metric Display Flow**:
    *   Baseline λBP Value → Associated Label for Baseline Track.
    *   Threat HR Value → Associated Label for Threat Track.
*   **Track Length Determination Flow**:
    *   Normalized Reference Length (1) → Defines the length of the gray Baseline Track.
    *   Threat Hazard Ratio (HR) → Calculates the relative length of the red Threat Track as `1/HR`.
*   **Endpoint Marking Flow**: Right endpoint of each track (Baseline and Threat) → Position for the LLM Forfeit Icon.
*   **Contextual Information Flow**: Subtitle → Provided as a global explanation for the entire infographic.

## Groupings

    *   Arrangement: Stacked vertically, one for each LLM.

*   **Provider Identity Block**:
    *   Components: Model Identity Badge, Model Name.
    *   Arrangement: Badge is placed to the far left, immediately preceding the Model Name.

## Key Relationships

*   **Vertical Stacking Order**: Model Rows are stacked in the precise order: Gemini-2.5-flash, Qwen3-Next-80B, GPT-OSS-20B, Nemotron-3-Nano-30B.
*   **Vertical Track Alignment**: Within each Model Row, the gray Baseline Track is positioned directly above the red Threat Track.
*   **Horizontal Alignment**: The left endpoints of all gray Baseline Tracks are aligned horizontally. The left endpoints of all red Threat Tracks are aligned horizontally with their respective Baseline Tracks.
*   **Relative Track Length**: The length of the red Threat Track is visually scaled to `1/HR` relative to the length of the gray Baseline Track, which is normalized to a reference length of 1.
    *   Gemini-2.5-flash: Threat Track length = 27% of Baseline Track length.
    *   Qwen3-Next-80B: Threat Track length = 33% of Baseline Track length.
    *   GPT-OSS-20B: Threat Track length = 91% of Baseline Track length.
    *   Nemotron-3-Nano-30B: Threat Track length = 54% of Baseline Track length.
*   **Endpoint Association**: An LLM Forfeit Icon is placed at the right endpoint of *every* track (both Baseline and Threat).
*   **Label Association**: Each Provider Identity Badge is placed next to its corresponding Model Name. Each Hazard Value Label (λBP, HR) is placed next to its respective track.

## Sequential vs Parallel

*   **Layout Construction**: The infographic is built by arranging visual elements. The Model Rows are stacked sequentially (vertically). Within each row, the components (badge, name, tracks, icon) are arranged horizontally.
*   **No Computational Parallelism**: The description pertains to the static visual layout of results, not to computational processes that would occur in parallel or sequence.

## Mathematical Operations

*   **Track Length Calculation**: The length of the Threat Track is derived from the Hazard Ratio (HR) using the formula:
    *   `Threat Track Length = Baseline Track Length * (1 / HR)`
    *   Given Baseline Track Length is normalized to 1, this simplifies to: `Threat Track Length = 1 / HR`.
*   **Specific Metric Values**:
    *   Gemini-2.5-flash: λBP = 0.23%, HR = 3.67×. (Calculated Threat Length ≈ 0.271, represented as 27%)
