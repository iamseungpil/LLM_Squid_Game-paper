# writer r1

최신 범위인 공간 확보에 맞추어 새 절과 그림 설명에 `예상!`을 표시했다. 새 절은 분석 전 집필 자리임을 첫 문장에서 명시한다. 분배 시점과 금액, 대화의 이유와 실제 토큰 이동을 대조할 항목만 적었다. 실제 전략의 존재, 모델별 차이, 생존에 미친 효과는 추가하지 않았다. Astra 이름이나 새 수치 및 인용은 넣지 않았다. evidence/는 읽거나 사용하지 않았다.

초록은 보조 실험 결론을 삭제하고 기존 정량 결과를 v20 예비 결과로 명시했으며 자리당 점수를 Sen 지수로 고쳤다. 서론은 보조 실험의 본문 예고를 예정 분석의 범위로 바꾸었다. 정의 절은 꺼짐 문구의 보조 실험 비교만 제거했다. 논의는 보조 실험의 충전 이유, 잔량 쪽지와 내부 사용량, Opus 수치에 의존한 부분을 제거하고 Sen 지수 명칭을 반영했다. 기존 아레나의 관측 수치, 수식, 필요한 삭제 외 인용 키, 그림 1은 보존했다.

프로필의 느낌표 금지는 사용자의 명시적 `예상!` 요청에 한해 적용하지 않았다. L2 흔적은 넣지 않았다. draft_r1/의 다섯 파일과 이 기록만 작성했다. 부모 에이전트가 원본 적용과 빌드를 담당한다.
